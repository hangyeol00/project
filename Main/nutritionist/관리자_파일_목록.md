## 🔐 인증/권한 관련 (필수)

### 2. UserSession.cs
- **역할**: 사용자 세션 및 권한 관리
- **핵심 기능**: `IsAdmin` 속성으로 관리자 여부 판단
- **위치**: `Main/nutritionist/UserSession.cs` (20줄)

### 3. LoginForm.cs
- **역할**: 로그인 인증 (관리자 포함)
- **핵심 기능**: 
  - 관리자 계정 인증
  - UserSession 생성 (Role = "ADMIN")
- **위치**: `Main/nutritionist/LoginForm.cs` (256줄)

### 4. Program.cs
- **역할**: 애플리케이션 진입점 및 라우팅
- **핵심 기능**: 
  - 로그인 후 관리자 여부 확인
  - 관리자면 `AdminForm` 실행, 아니면 `NutritionistForm` 실행
- **위치**: `Main/nutritionist/Program.cs` (73줄)
- **관련 코드**: 35-42줄 (관리자 라우팅 로직)

## 🗄️ 데이터베이스 관련 (필수)

### 5. DatabaseHelper.cs
- **역할**: 데이터베이스 작업 헬퍼 클래스
- **핵심 기능**: 
  - `ExecuteDataTable()` - 데이터 조회
  - `ExecuteScalar()` - 단일 값 조회
  - `ExecuteNonQuery()` - INSERT/UPDATE/DELETE
  - `ToInt()`, `ToIntNullable()` - 타입 변환
- **위치**: `Main/nutritionist/DatabaseHelper.cs` (약 140줄)
- **사용**: AdminForm에서 모든 DB 작업에 사용

### 6. DatabaseConfig.cs
- **역할**: 데이터베이스 연결 설정
- **핵심 기능**: ConnectionString 정의
- **위치**: `Main/nutritionist/DatabaseConfig.cs` (11줄)

## 🔍 관리자 기능 상세

### AdminForm.cs 주요 기능:

1. **발주 승인** (`LoadPurchaseRequests`, `BtnApprovePurchase_Click`, `BtnRejectPurchase_Click`)
   - 발주 요청 목록 조회
   - 승인/거부 처리
   - 거부 사유 입력 및 저장

2. **식단 계획 승인** (`LoadMealPlansForApproval`, `BtnApproveMealPlan_Click`, `BtnRejectMealPlan_Click`)
   - DRAFT 상태 식단 조회
   - 승인 처리
   - 거부 사유 입력

3. **학생 알레르기 관리** (`LoadStudents`, `BtnAddAllergy_Click`, `BtnRemoveAllergy_Click`)
   - 학생 목록 조회
   - 알레르기 추가/삭제
   - 학생별 알레르기 목록 조회

4. **대시보드** (`LoadDashboard`)
   - 총 학생 수
   - 오늘 급식 인원
   - 승인 대기 발주 요청 수
